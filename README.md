Japanese Gut Microbiome Analysis

Overview

This project presents a 16S rRNA gut microbiome analysis using sequencing data from a Japanese gut microbiome dataset.

The analysis was performed using both the mothur workflow through the Galaxy platform and the DADA2 pipeline in R.

Objectives

- Process and analyze 16S rRNA sequencing data.
- Assess sequencing quality.
- Develop a reproducible microbiome analysis workflow.
- Compare microbiome processing approaches using mothur and DADA2.
- Generate ASV and taxonomic classification tables.
- Perform downstream microbiome analysis and visualization.

Analysis Workflow

Galaxy / mothur

The sequencing data were processed using mothur through the Galaxy platform.

A reproducible Galaxy workflow was developed and saved to document the analysis steps.

DADA2 in R

The analysis was reproduced using the DADA2 pipeline in R.

The workflow included:

1. Sequencing quality assessment
2. Quality filtering
3. Error-rate assessment
4. DADA2 processing
5. ASV generation
6. Taxonomic classification
7. Downstream microbiome analysis
8. Visualization of results

Outputs

The project generated:

- Sequencing quality profiles
- Error-rate plots
- Amplicon Sequence Variant (ASV) table
- Taxonomy table
- Microbiome analysis visualizations
- Summary results
